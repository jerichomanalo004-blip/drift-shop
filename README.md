# DRIFT – Streetwear E‑commerce Platform

A full‑featured e‑commerce platform for premium streetwear. Built with PHP (PDO), MySQL, HTML/CSS/JS.

## Features
- Customer authentication (register, login, password reset)
- Product catalog with search, filters, sorting, pagination
- Shopping cart and wishlist (AJAX‑powered)
- Secure checkout and order history
- Customer review system with star ratings
- Admin dashboard with revenue analytics, inventory management, order fulfillment, and stock logs
- Responsive design with dark/light mode toggle

## Disclaimer

No actual products are sold, and no revenue is generated.
